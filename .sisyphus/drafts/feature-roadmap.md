# KOSE - Feature Roadmap

## Fitur Pilihan User (5):

### 1. Kalkulator Biaya Hidup
- Input: budget, makan, transport, listrik, dll
- Output: total estimasi, breakdown chart, sisa budget
- Relasi: Budget Planner

### 2. Neighborhood Map
- POI markers: warteg, ATM, minimarket, mosque, dll
- Distance calculator ke POI terdekat
- Walking/driving time estimate
- Relasi: Area Safety Score, Transit Score

### 3. Quick Match Quiz
- Quiz step-by-step (budget, tipe, fasilitas, lokasi, transportasi)
- Output: 3-5 kost recommendations + match percentage
- Progress bar + save/share result

### 4. Kost Sekitar Kampus
- Campus selector (UI, UGM, ITB, UNAIR, UB, dll)
- Distance filter (1km, 3km, 5km, 10km)
- Sort by distance + campus map overlay

### 5. Transit Score
- Overall score (1-10) based on:
  - Jarak ke kampus/stasiun/mall
  - Akses angkut umum
  - Kondisi jalan
- Breakdown per category
- Route suggestions + Commute Calculator
